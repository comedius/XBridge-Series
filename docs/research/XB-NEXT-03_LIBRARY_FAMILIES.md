## 3. Cross-family constraints

1. `documented (project-authored)` S0/S9: this package records public evidence only; no external code, license or implementation is adopted. The pinned external crates declare GPL-3.0-or-later in S3/S6; owner/legal review would be required before any adoption.
2. `documented (project-authored)` S1: source status vocabulary includes `implemented`, `stub`, `forwarded`, `missing` and title-specific classifications. These are observations about an external project, not XBridge capability status and not proof of compatibility.
3. `unknown`: no real Xbox Series X game was run, no package was decrypted, and no game import table was used as executable evidence. S10 records why retail package internals remain unknown.
4. `unknown`: the set of library families required by arbitrary commercial binaries. The five families above are known public leads only.
5. `documented (authoritative, public PC/Windows D3D12 only)` S8: D3D12 binding, barriers, PSOs and command queues are documented for Windows. This must not be presented as Xbox D3D12.X proof; see `docs/research/XB-NEXT-03_GRAPHICS_ANALYSIS.md`.
